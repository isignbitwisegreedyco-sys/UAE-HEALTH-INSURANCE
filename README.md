# ClearCover — UAE Health Insurance

A responsive informational website concept for UAE residents comparing health insurance. Its core promise is transparent plan information, no brokerage markup added by ClearCover, and payment directly to the chosen insurer.

## Run locally

Open `index.html` in a browser. The quote form is a client-side demonstration only; it does not connect to insurers, collect or transmit personal data, or provide a live premium. Final prices, eligibility, and policy terms must be confirmed by the insurer.
